# AutoMind LK

An AI-powered automotive platform designed for the Sri Lankan vehicle market.

## Project Modules

- **AutoCheck** — AI-assisted vehicle inspection and reporting.
- **AutoValue** — Machine learning-based vehicle price estimation.
- **AutoAssist** — Agentic AI and RAG-powered automotive assistant.
- **Marketplace** — Vehicle advertisements, search and filtering.
- **Administration** — User management and marketplace moderation.

## Technology Stack

- Frontend: React, TypeScript, Vite, Tailwind CSS
- Backend: Python, FastAPI
- Database: Supabase PostgreSQL
- Authentication: Supabase Auth
- Artificial Intelligence: Gemini, LangGraph
- Machine Learning: Scikit-learn, XGBoost
- Infrastructure: Docker, Redis
- Testing: Pytest, Postman
